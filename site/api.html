Open API

Every Flowscope dataset is a static JSON file. No API key, no auth, no rate limits. Fetch them straight from any static host — or self-host the data/ folder yourself.

Base URL

https://flowscope.example.com/data

On this site the files live at ../data/*.json relative to any page. Replace the base URL with wherever you host them.
